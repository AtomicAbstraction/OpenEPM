# Open EPM

Open EPM is a self-hosted, programmable multidimensional application platform for planning, forecasting, simulation, operational analysis, workflow, and consolidation compositions.

This repository is the public software home for the application served at `app.openepm.dev`. The separate `openepm.dev` website and documentation-site source are not part of this repository.

## Publication status

The repository governance structure is initialized. Application source and downloadable releases will be published only after the clean-source boundary, security, licensing, build, and qualification gates have passed. Until a release is published, this repository must not be treated as an installable or production-ready distribution.

## Community

- Use Issues for reproducible bugs, feature proposals, and documentation improvements.
- Use Discussions for questions and ideas.
- Submit code changes through pull requests. The project owner makes the final merge decision.
- Report security vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
