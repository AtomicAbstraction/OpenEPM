# Contributing to Open EPM

Thank you for helping improve Open EPM.

1. Search existing Issues and Discussions before opening a new item.
2. Use the relevant issue template and provide a minimal, reproducible example.
3. Discuss material behavior or architecture changes before implementation.
4. Fork the repository and submit changes through a focused pull request.
5. Add or update tests for changed behavior and ensure required checks pass.
6. Do not include credentials, private data, proprietary material, or source from the separate `openepm.dev` website.

Submitting a contribution does not guarantee acceptance. The project owner retains final authority over the official source and releases. Unless explicitly stated otherwise, contributions intentionally submitted for inclusion are provided under the repository's MIT License.
